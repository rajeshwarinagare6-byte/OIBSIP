
# Voice Assistant Using Python

## 1. Project Overview
This project is a simple voice assistant developed using Python. It listens to voice commands through a microphone and responds to the user through speech.

## 2. Technologies Used
- Python 3.13
- SpeechRecognition
- pyttsx3
- PyAudio
- datetime
- webbrowser
- urllib

## 3. Features
- Greets the user when they say Hello.
- Announces the current time.
- Announces today's date.
- Performs Google searches using voice commands.
- Handles commands it does not understand.
- Provides spoken responses.
- Exits when the user says Exit or Stop.

## 4. Installation

Install the required libraries:

pip install SpeechRecognition pyttsx3 pyaudio

## 5. How to Run

1. Open the project folder in VS Code.
2. Install the required libraries.
3. Connect or enable your microphone.
4. Run the following command:

python voice_assistant.py

## 6. Sample Voice Commands
- Hello
- What is the time?
- What is the date?
- Search for Python programming
- Exit
