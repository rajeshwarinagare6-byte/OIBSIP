
# Python Voice Assistant

## About the Project
A beginner-friendly voice assistant developed using Python. It recognizes voice commands and responds using speech.

## Technologies Used
- Python
- SpeechRecognition
- pyttsx3
- PyAudio

## Features
- Voice recognition
- Speech responses
- Greeting messages
- Voice commands

## Installation

Install dependencies:

pip install -r requirements.txt

## How to Run

python voice_assistant.py
